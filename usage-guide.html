KakaoTalk CLI
macOS · Codex & Claude Code

비공식 실험용 프로젝트입니다. 카카오의 검토·승인·인증을 받지 않았으며, 카카오가 제공하거나 지원하는 공식 CLI가 아닙니다.

실제 메시지·파일 전송은 아직 검증하지 않았습니다. 먼저 본인 채팅방에서 전송 없이 테스트하세요.

  1. 앱을 열고 사용자 앱 폴더에 설치를 누릅니다.
  2. 손쉬운 사용 권한 설정 열기를 누르고, 시스템 설정에서 KakaoTalk CLI를 추가·허용합니다.
  3. 앱으로 돌아와 상태 다시 검사를 누릅니다.
  4. CLI + Codex·Claude Code 스킬 설치를 누릅니다. 새 대화부터 스킬을 사용할 수 있습니다.

처음 실행

~/.local/bin/cli-anything-kakaotalk --json doctor
~/.local/bin/cli-anything-kakaotalk --json chat search "채팅방 이름"
~/.local/bin/cli-anything-kakaotalk --json chat open "정확한 채팅방 이름"

카카오톡을 실행하고 로그인한 상태에서 사용합니다. 잠긴 화면·로그아웃·완전한 백그라운드 실행은 지원하지 않습니다. 채팅방을 열면 읽음 상태가 바뀔 수 있습니다. 방 이름이 같은 채팅방은 구분할 수 없으므로 이름을 고유하게 설정하세요.

초안과 전송

cli-anything-kakaotalk --json message draft --room "정확한 방 이름" --text-file -
cli-anything-kakaotalk --json chat current --room "정확한 방 이름"

--text-file -는 표준입력에서 문구를 읽습니다. 전송은 별도 message send 명령이며 --confirm-room과 --request-id가 필요합니다. 현재 초안이 전송 문구와 일치해야 합니다. UI에서 Enter를 한 번 누른 결과는 서버 전달 여부를 증명하지 못하므로 status: unknown으로 반환합니다. 결과를 확인하지 않고 재시도하지 마세요.

파일 선택창 열기·취소는 file dialog / file cancel입니다. file send는 실전 전송 검증 전인 실험 기능입니다. 전체 대화 이력 추출이나 수신 감시는 제공하지 않습니다.

설치 위치와 제거

앱은 ~/Applications/KakaoTalk CLI.app, CLI 연결은 ~/.local/bin/cli-anything-kakaotalk, 스킬 연결은 ~/.codex/skills/cli-anything-kakaotalk 및 ~/.claude/skills/cli-anything-kakaotalk입니다. 기존 파일은 덮어쓰지 않습니다. 앱은 설치 후 이동하지 마세요.

전송 요청의 ID·해시·상태만 ~/Library/Application Support/KakaoTalkCLI에 기록합니다. 대화 내용은 기록하지 않지만 명령의 출력과 터미널 기록에는 내용이 남을 수 있습니다. 앱·세 연결·상태 폴더를 제거하고 시스템 설정에서 권한을 해제하면 제거됩니다. 실행한 전송은 취소되지 않습니다.

설치 경로

사용자 앱 폴더에 설치한 뒤 원래 앱을 종료하고 Finder에서 ~/Applications/KakaoTalk CLI.app을 직접 여세요. 이 설치 앱에만 손쉬운 사용 권한을 부여하세요. CLI와 스킬은 이 고정 경로를 사용합니다. AppTranslocation 오류가 계속되면 회사 정책에 따른 개별 앱 승인을 확인하세요.

호환성

Apple Silicon, macOS 14 이상 대상입니다. 카카오톡 26.5.0은 기존 기능, 26.8.0은 검색·열기·초안·읽기·파일 선택창 열기/취소를 지원합니다. 26.8.0 파일 선택·전송은 기본 차단됩니다. doctor의 supported_operations를 확인하세요. 명령별 실제 검증 범위는 함께 제공된 검증 보고서를 확인하세요. Apple 공증 없이 로컬 임시 서명된 앱이며 다른 Mac 배포 시 추가 서명·공증이 필요합니다.
