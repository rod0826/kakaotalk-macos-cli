# KakaoTalk 버전별 검증 범위

버전 번호만으로 전체 기능을 허용하지 않습니다. 설치된 카카오톡의 **정확한 버전과 요청한 작업**을 함께 확인합니다.

| 카카오톡 버전 | 기본 허용 작업 | 검증 근거와 제한 |
| --- | --- | --- |
| 26.5.0 | `search`, `open`, `current`, `draft`, `read`, `file-dialog`, `file-cancel`, `file-select`, `send`, `file-send` | 개발 환경에서 확인한 기존 작업 범위. 전송 명령의 실행 결과와 실제 전달 완료는 구분해야 합니다. |
| 26.8.0 | `search`, `open`, `current`, `draft`, `read`, `file-dialog`, `file-cancel` | [회사 맥북 테스트 보고](https://github.com/rod0826/kakaotalk-macos-cli/issues/5)에 따라 검색·대화방 열기·현재 상태·초안 작성/확인/삭제·로드된 대화 읽기·파일 선택창 열기/취소를 허용합니다. |
| 그 밖의 버전 | 없음 | 새 버전은 검증 후 작업별로 추가합니다. `26.8.1`처럼 패치 버전이 달라도 자동으로 허용하지 않습니다. |

`doctor` 진단은 모든 버전에서 사용할 수 있습니다. 진단의 `supported_operations`에서 현재 버전에 허용된 작업을 확인하세요. `version_matches`가 참이어도 모든 작업이 검증되었다는 뜻은 아닙니다.

26.8.0의 **파일 선택(`file-select`), 메시지 전송(`send`), 파일 전송(`file-send`)은 아직 검증되지 않았습니다.** 회사 테스트 보고에는 이 작업들의 성공 결과가 없으므로 기본 허용 목록에 포함하지 않습니다. 실제 전송을 확인하기 전에는 전송 지원 완료로 안내하지 마세요.

기존 `--allow-untested-version`은 검증되지 않은 버전이나 작업을 명시적으로 시험할 때만 사용하는 선택 사항입니다. 이 옵션은 호환성을 보장하지 않으며, 수신자·내용·전송 확인과 중복 방지 조건을 생략하지 않습니다. 회사 맥북에서는 먼저 기본 허용 작업을 다시 확인하고, 추가 작업은 별도로 시험한 결과를 기록해 주세요.
