26.9.0 실앱 검증은 새 네이티브 백엔드를 직접 호출했습니다. 무작위 검색 반복, 정확한 본인 방 열기, 현재 상태, 초안 작성·복원, 읽기 10회, 파일 선택창 열기·취소를 확인했습니다. 메시지나 파일은 발송하지 않았으며, 이를 설치된 frozen CLI의 브로커 IPC 검증이나 다른 Space 검증으로 확대하지 않습니다.

추가로 오래 실행 중인 제어 앱이 Bundle 캐시의 과거 버전을 반환하는 현상을 발견했습니다. 0.1.3은 디스크 버전을 매번 새로 읽고, 앱 파일이 카카오톡 실행 후 변경된 것으로 보이면 APP_RESTART_REQUIRED로 UI 작업을 중단합니다. 이 시각 검사는 보수적인 단서이며 실행 중인 코드의 정확한 버전을 증명하지 않습니다.

0.1.3은 개선 릴리스입니다. 고정 인증서 기반 배포, 회사 설치 및 최신 카카오톡 실제 발송을 모두 검증한 정식 1.0 완성으로 표시하지 않습니다.
