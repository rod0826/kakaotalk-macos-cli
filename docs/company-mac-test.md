# 회사 맥북 테스트 (별도 전달 ZIP)

**카카오의 검토·승인·인증을 받지 않은 비공식 실험용 프로젝트입니다. 카카오가 제공하거나 지원하는 공식 CLI가 아닙니다.**

이 ZIP은 회사 맥북에서 제한적으로 테스트하기 위해 별도로 전달한 Apple Silicon 빌드입니다. GitHub Releases에는 게시하지 않습니다.

1. Apple Silicon(M1 이상), macOS 14 이상인지 확인합니다. 실제 검증 OS는 macOS 26.6.2이며 14는 빌드 최소값입니다. 카카오톡은 26.5.0만 검증했습니다. 버전이 다르면 기본적으로 UI 제어가 중단됩니다.
2. ZIP의 SHA-256을 제공된 체크섬과 비교하고 압축을 풉니다. `시작하기.html`을 먼저 읽습니다.
3. 앱을 열고 **사용자 앱 폴더에 설치**를 누릅니다. 이 앱은 Developer ID 서명·Apple 공증을 받지 않은 로컬 임시 서명 빌드이므로 새 Mac의 Gatekeeper가 실행을 차단할 수 있습니다. 이 경우 macOS가 제공하는 개별 앱 허용 절차와 회사 정책에 따라 처리하고, 허용되지 않으면 중단합니다. 보안 기능을 일괄 해제하는 명령은 제공하지 않습니다.
4. 설치된 `KakaoTalk CLI` 앱의 **손쉬운 사용 권한 설정 열기**에서 해당 앱만 추가·허용합니다. 원래 Mac의 권한은 이전되지 않습니다. 회사 정책으로 막히면 관리자에게 승인받아야 합니다.
5. **상태 다시 검사**, **CLI + Codex·Claude Code 스킬 설치**를 누릅니다. 카카오톡을 실행·로그인하고 화면 잠금을 해제한 상태에서 테스트합니다.
6. 터미널에서 `~/.local/bin/cli-anything-kakaotalk --json doctor`를 실행합니다. `accessibility_trusted`, `running`, `version_matches`를 확인합니다.
7. 고유한 이름의 본인 채팅방으로 검색·열기, 초안 입력·복원, 파일 선택창 열기·취소만 먼저 확인합니다. 채팅방을 열면 읽음 표시가 바뀔 수 있습니다.

실제 메시지와 파일 전송은 검증하지 않았습니다. 초기 테스트에서 `message send`와 `file send`는 실행하지 마세요. 기존 초안을 확인한 뒤 변경하며, 테스트 후 원래대로 복원합니다.

오류를 공유할 때는 macOS/카카오톡 버전, 오류 코드, 수행 명령의 종류만 먼저 알려주세요. 채팅 내용·방 이름·개인 경로는 지우세요. 앱을 다시 빌드하면 임시 서명이 바뀌어 권한 재설정이 필요할 수 있습니다.
