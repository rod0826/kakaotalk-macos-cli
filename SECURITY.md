# Security and privacy

This unofficial experimental tool controls the logged-in KakaoTalk GUI using macOS Accessibility permission. Only grant that permission if you trust the code. It does not access login tokens or the internal chat database.

Do not include chat text, contact/room names, screenshots, credentials, local journals or private file paths in public issues. For a sensitive vulnerability, contact the maintainer privately through their GitHub profile; do not publish exploit details or personal logs in an issue.

Sending is experimental and delivery is not verified. An uncertain result must never trigger an automatic retry. Use a unique self-chat for initial testing. Manual interaction with the same GUI can invalidate checks. Company-managed Macs may require administrator approval; do not bypass management or endpoint security policies.
